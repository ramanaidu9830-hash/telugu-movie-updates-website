TELUGU MOVIE UPDATES - STARTER WEBSITE

FILES
- index.html: website structure
- style.css: design and responsive layout
- script.js: sample posts and add/edit/delete functionality

RUN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension (optional but recommended).
4. Right-click index.html and choose "Open with Live Server".

EDIT CONTENT
- Scroll to "Add / Edit Movie Updates" on the website.
- Enter a title, category, image URL or upload an image, and description.
- Click Publish Update.
- Use Edit or Delete on a card to manage it.

IMPORTANT LIMITATIONS
- Posts are saved in localStorage in the current browser only.
- They do not automatically appear on another device or for all visitors.
- Uploaded images are stored in this browser and may use browser storage space.
- This editor is not a secure admin panel. Anyone who can open the page can use it.
- For a real public news site with shared posts, use a CMS or backend later.
- Use images you own, have permission to use, or that are licensed for reuse.
- Add your own About, Contact, Privacy Policy and editorial/source information before launch.
